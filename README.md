## 📖 Sobre o projeto

Este repositório reúne as atividades, projetos e exercícios desenvolvidos
durante as aulas de Programação Web III (PW III), utilizando diferentes
tecnologias e conceitos relacionados ao desenvolvimento de aplicações web.

Os projetos presentes no repositório abordam conteúdos como desenvolvimento
de interfaces, JavaScript, PHP, banco de dados, operações CRUD, autenticação
de usuários e organização de aplicações web.

## 📂 Projetos e atividades

### 💼 Portfólio

Projeto desenvolvido para apresentação e organização dos trabalhos e
atividades realizadas durante a disciplina.

### ⚙️ Operações

Atividade desenvolvida para aplicação de operações utilizando JavaScript,
explorando conceitos de programação e interação com a aplicação web.

### 🌎 CRUD Mundo

Aplicação web para gerenciamento de informações geográficas.

## 💻 Tecnologias utilizadas

As tecnologias utilizadas variam de acordo com cada atividade e projeto
