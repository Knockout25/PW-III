## 📖 Sobre o projeto

O CRUD Mundo é uma aplicação web para gerenciamento de informações
geográficas, permitindo o cadastro, consulta, alteração e exclusão
de registros relacionados a cidades, estados, países, continentes e
outras informações do sistema.

O projeto também possui um sistema de autenticação de usuários,
incluindo login, recuperação de senha e geração de senha temporária.

## ⚙️ Funcionalidades

### 🌎 Gerenciamento de dados

- Cadastro, consulta alteração e exclusão de continentes
- Cadastro, consulta alteração e exclusão de países
- Cadastro, consulta alteração e exclusão de governantes
- Cadastro, consulta alteração e exclusão de estados
- Cadastro, consulta alteração e exclusão de cidades

### 🔐 Autenticação

- Cadastro de usuários
- Login
- Logout
- Recuperação de senha
- Geração de senha temporária
- Alteração de senha

## 📁 Estrutura do projeto

O projeto está organizado em arquivos e pastas de acordo com suas
responsabilidades, separando os recursos de interface, lógica da
aplicação e acesso aos dados.

## 🚀 Como executar

1. Instale o XAMPP.
2. Coloque o projeto no diretório `htdocs` do XAMPP.
3. Configure o banco de dados MySQL.
4. Inicie os módulos Apache e MySQL pelo XAMPP.
5. Acesse o projeto pelo navegador.
